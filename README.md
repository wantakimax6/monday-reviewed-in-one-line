# Monday, Reviewed in One Line

Entry for the [make.fun bounty "Monday, Reviewed in One Line"](https://make.fun/bounty/u-zeroxfive-monday-reviewed-in-one-line-e55de3c1): the funniest one-line review of my own Monday, under 200 characters.

> Monday, reviewed: my inbox had 63 unread emails, my calendar had 6 meetings, and my motivation had left the group chat.

`main.ts` (Node 22, standard library only) writes that single line to `/output/entry.txt`.
